# 사용자 작업 지침 (User Instructions & Preferences)

1. **문서 한글 작성 규칙**:
   - 모든 `.md` 파일 및 사용자 설명은 100% 한국어로 작성합니다 (영문 금지).

2. **간결하고 깔끔한 코드 작성 (Clean & Concise Code)**:
   - 코드 작성 시 불필요한 공백, 군더더기 주석, 사용하지 않는 복잡한 추상화를 지양하고 필요한 핵심 로직만 간결하고 직관적으로 작성합니다.

3. **철저한 실시간 실행 검증 (Continuous Testing & Iterative Debugging)**:
   - 기능을 구현하는 동안 틈틈이 테스트 코드를 실행 및 검증합니다.
   - 에러 발생 시 원인을 파악하고 에러가 완벽히 해결될 때까지 수정 및 재테스트를 반복합니다.
   - 검증 없이 작성이 완료되었다고 하지 않습니다.

4. **비전공자 눈높이 맞춤 요약 (Easy Non-Technical Summary)**:
   - 단계별 작업 완료 후 핵심 변경 사항을 비전공자도 쉽게 이해할 수 있도록 명확하고 쉬운 언어로 요약하여 전달합니다.
