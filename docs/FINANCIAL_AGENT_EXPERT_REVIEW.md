## 🏛️ [1] 금융권(Finance) 관점 진단: 부족한 점 & 보완할 점

### 1. 🏢 기업명 ↔ 고유코드(corp_code / stock_code) 자동 매핑 미비
- **부족한 이유**: DART API는 "삼성전자"라는 이름이 아니라 `00126380`이라는 8자리 고유 코드를 요구합니다.
- **개선점**: 사용자가 "삼성전자", "SK하이닉스"라고 검색하면 자동으로 고유 코드(corp_code) 및 주식 종목코드(005930)로 변환해 주는 **'기업 사전(Corp Dictionary) 매핑 도구'**가 필수적입니다.

### 2. 📊 주가 실시세 및 정량 재무제표(PER/PBR/ROE) 분석 부재
- **부족한 이유**: 현재는 공시 제목/뉴스 위주의 텍스트 분석에 치우쳐 있습니다. 실제 금융 분석은 **"주가(KOSPI/KOSDAQ 종목별 시세)"**와 **"재무제표(매출, 영업이익, 부채비율)"**라는 숫자 데이터가 필수입니다.
- **개선점**: Naver Pay 증권 / 한국투자증권 API / Yahoo Finance를 연동하는 **'종목 시세 및 재무제표 조회 Tool'**을 추가해야 합니다.

### 3. ⚖️ 금융 감달/컴플라이언스 감사 이력(Audit Trail) 보관 미비
- **부족한 이유**: 금융권에서는 AI가 어떤 이유로 이 분석을 내놓았는지 추적할 수 있어야 합니다 (전자금융거래법 및 규제준수).
- **개선점**: Agent의 모든 `생각(Think) -> 도구 실행(Act) -> 결과(Observe)` 과정을 타임스탬프와 함께 DB에 영구 기록하는 **'감사 트레일(Audit Trail)'** 시스템이 보완되어야 합니다.

## 🤖 [2] AI Agent 시스템 관점 진단: 부족한 점 & 보완할 점

### 1. 🔄 자아 비판 및 검증 루프 (Self-Reflection Loop) 약화
- **부족한 이유**: 현재 Multi-Agent 팀의 `ComplianceAgent`는 원문과 텍스트 유무만 체크하는 단순 구조입니다.
- **개선점**: 최종 답변을 사용자에게 주기 전, **'비판가 에이전트(Critic Agent)'**가 답변을 스스로 검토하고 부족하면 수정을 요구하는 **'자기 반성(Reflection Loop)'**을 1~2회 거치도록 개편해야 합니다.

### 2. 🔍 하이브리드 RAG (BM25 단어 검색 + Vector 시맨틱 검색) 부재
- **부족한 이유**: 현재 Vector Memory는 문맥 위주 검색(TF-IDF/Cosine)만 수행하므로 "2026-08-01", "제2026-15호" 같은 **정확한 숫자/고유번호 검색(키워드 검색)**에 약합니다.
- **개선점**: 정밀 키워드 검색(BM25)과 시맨틱 검색(Vector)을 융합한 **'하이브리드 RAG'**로 고도화해야 합니다.

### 3. 🗑️ 삭제 및 정리해야 할 유산 코드 (Legacy Code)
- **삭제 대상**: 이전 스케줄러 방식의 단방향 하드코딩 파이프라인 중 중복되는 옛 잔재 스크립트들을 정리하여 코드베이스를 깔끔하게 다듬어야 합니다.

## 📋 고도화 4대 핵심 과제 요약표 (비전공자 맞춤)

| 영역 | 부족한 점 (현재) | 고도화 방향 (개선 후) | 비전공자용 한 줄 설명 |
|---|---|---|---|
| **금융** | 기업명 ↔ 코드가 연결 안 됨 | 기업명 검색 시 코드로 자동 변환 | "삼성전자" 치면 알아서 번호를 찾아 공시 조회 |
| **금융** | 주가 및 재무 수치가 없음 | 실시간 주가 및 재무제표 Tool 추가 | 텍스트만 보지 않고 주가와 매출 수치도 함께 분석 |
| **Agent** | 단순 1회성 답변 작성 | 자기 반성(Reflection) 검증 루프 구축 | 답변 내기 전 스스로 "오류 없나?" 한 번 더 검토 |
| **Agent** | 숫자/날짜 정확도 부족 | 하이브리드 RAG (키워드+문맥) 도입 | 숫자, 조항 번호 하나도 틀리지 않고 정확 검색 |

## 🎯 향후 고도화 진행 추천 순서

1. **[고도화 1단계]** 기업명 ↔ corp_code 자동 변환 매핑 및 주가/재무제표 조회 Tool 추가

3. **[고도화 3단계]** BM25 + Vector 하이브리드 RAG 및 잔재 코드 정리
